# VS Code Profiles

Coleção de **perfis personalizados para o Visual Studio Code**, organizados de acordo com diferentes áreas de desenvolvimento.

O objetivo deste repositório é manter configurações, extensões e preferências do VS Code separadas para cada stack, facilitando a troca de ambiente sem precisar configurar o editor manualmente.

## 📂 Perfis disponíveis

| Perfil        | Arquivo                             | Foco                   |
| ------------- | ----------------------------------- | ---------------------- |
| 🐦 Flutter    | `Flutter.code-profile`              | Flutter e Dart         |
| 🌐 Frontend   | `Frontend.code-profile`             | HTML, CSS e JavaScript |
| ☕ Java Spring | `Java Spring (custom).code-profile` | Java e Spring Boot     |

---

## 🚀 Como utilizar

### 1. Clone o repositório

```bash
git clone https://github.com/JoseJacsanCode/profiles-vscode.git
```

Entre no diretório:

```bash
cd profiles-vscode
```

### 2. Importe um perfil no VS Code

No Visual Studio Code:

1. Abra o menu de **Perfis**.
2. Selecione **Import Profile...**.
3. Escolha o arquivo `.code-profile` desejado.
4. Confirme a importação.
5. Ative o perfil.

Você também pode utilizar diretamente os arquivos disponíveis neste repositório.

## 🎨 Tema

Os perfis utilizam o tema **Night Owl** como padrão, proporcionando uma interface escura e uma paleta de cores voltada para programação.

O tema de ícones utilizado é o **vscode-icons**.

---

## 🔧 Personalização

Os arquivos `.code-profile` armazenam as configurações e extensões específicas de cada ambiente.

Isso permite adaptar cada perfil sem interferir nas configurações dos demais.

Por exemplo:

* Projetos Flutter → perfil **Flutter**
* Projetos Web → perfil **Frontend**
* Projetos Java/Spring Boot → perfil **Java Spring**

---

## 📌 Objetivo

Este repositório serve como um **backup e catálogo das configurações pessoais do VS Code**, permitindo reproduzir rapidamente o ambiente de desenvolvimento em outra instalação ou computador.

Também pode servir como referência para quem deseja organizar o VS Code por **stack ou área de desenvolvimento**.
